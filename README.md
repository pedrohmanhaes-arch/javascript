# 🟨 JavaScript

Repositório dedicado aos meus estudos de **JavaScript**, reunindo exercícios, aulas, desafios e projetos desenvolvidos ao longo da minha jornada de aprendizado em desenvolvimento web.

O objetivo é construir uma base sólida em JavaScript, desde os fundamentos da linguagem até conceitos mais avançados e aplicações práticas.

---

## 🎯 Objetivos

- Aprender e consolidar os fundamentos de JavaScript
- Desenvolver lógica de programação
- Praticar manipulação do DOM
- Trabalhar com funções, arrays e objetos
- Compreender conceitos de programação orientada a objetos
- Criar aplicações utilizando JavaScript
- Desenvolver projetos práticos
- Evoluir posteriormente para frameworks e tecnologias do ecossistema JavaScript
